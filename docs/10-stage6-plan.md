# План этапа 6 — банк и сверка

Основание: ТЗ §4 («Банковская сверка»), §11, `docs/05-roadmap.md` (этап 6: идемпотентный импорт, объяснимость, drill-down), решение владельца (2026-10-10): действовать «как считается правильным», спорное — в `docs/09-open-questions-recheck.md`.

## Принципы
- **Форматы выписок конкретных банков не выдумываются.** Поддерживается универсальный файл CSV/XLSX с **явным сопоставлением колонок** (профиль импорта, который задаёт пользователь, с предпросмотром). Готовых «форматов банков» в системе нет.
- Интеграции с банками/Multibank/Didox/Faktura.uz — этап 7; без официальной документации они имеют статус `NOT_CONFIGURED`/`MOCK`.
- Импорт **идемпотентен**: тот же файл повторно не создаёт дубли; перекрывающиеся выписки не дублируют операции.
- Сверка — **ручное подтверждение** человеком; система предлагает кандидатов с объяснением причин. Бухгалтерских проводок по банку не создаётся без правил бухгалтера (этап 5).
