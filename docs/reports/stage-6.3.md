# Отчёт: срез 6.3 — отчёты по банку (drill-down, CSV)

## Что сделано
- **Сводка по счетам и валютам** за период (`GET /bank/reports/summary`): накоплено до периода, поступления, списания, итог за период, накоплено на конец, число операций, сколько не сверено / сверено / пропущено, **неразнесённая сумма**. Фильтр по счёту.
- **Отчёт «Подтверждённые сопоставления»** (`/bank/reports/matches`): дата операции, счёт, сумма, документ, контрагент, кто подтвердил; отменённые не попадают; на экране до 1000 строк с пометкой «показаны первые…», полный список — в CSV.
- **CSV**: сводка, сопоставления, операции (с фильтром статуса). Разделитель `;`, BOM для Excel, `Cache-Control: private, no-store`, защита от формул (значения, начинающиеся с `= + - @`, получают апостроф).
- **Drill-down**: сводка → список операций (тот же счёт и период; число «не сверено/сверено/пропущено» открывает список с этим статусом) → операция → документ; строки отчёта сопоставлений ведут на операцию и документ. В списке операций появились фильтры дат.
- Интерфейс: вкладка «Отчёты», uz/ru/en. Права: `bank.read` (аудитор читает и экспортирует).
- **Найдена и исправлена ошибка среза 6.2**: интерфейс ждал статус сопоставления `ACTIVE`, сервер отдаёт `CONFIRMED`, поэтому подтверждённые сопоставления не показывались на странице операции и в панели документа. Тесты бэкенда её не видели (интерфейс не покрыт), поймал бы только сквозной E2E — он теперь добавлен.

## Ограничения и риски
- «Накоплено» — сумма **импортированных** операций, а не остаток по выписке банка: начальные остатки и контроль непрерывности выписок не реализованы.
- Отчёты без проводок и без курсов: суммы по валютам раздельно, пересчёта в базовую валюту нет.
- Отчёт сопоставлений на экране ограничен 1000 строк (CSV — полный).
- Переводы uz/en мои, носитель не проверял.
