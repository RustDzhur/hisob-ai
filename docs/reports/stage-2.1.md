# Отчёт: срез 2.1 — валюты организации и единицы измерения (этап 2, начало)

Дата: 2026-10-10. Среда: сервер Ubuntu 26.04 (Docker, PostgreSQL 16); статические проверки — macOS.

## Что реально работает
- **Валюты организации** (мультивалютность — основа): глобальный справочник из 6 валют (UZS, USD, EUR, RUB, KZT, CNY; реальные коды ISO 4217, по 2 знака после запятой) с названиями на uz/ru/en. Организация включает и отключает валюты; **базовая (по умолчанию UZS) всегда включена и не отключается** (409 `base_currency_locked`). При создании организации базовая валюта проверяется по справочнику (неизвестная → 422 `currency_unknown`). Существующие организации автоматически получили свою базовую валюту (миграция 0003, проверено на 146 организациях сервера: без базовой — 0).
- **Единицы измерения**: 5 системных (шт/dona/pcs, кг, г, л, м) видны всем организациям и неизменяемы; организация создаёт **свои** единицы (код + названия на uz/ru/en, хотя бы одно), правит названия, отключает/включает. Код уникален среди системных и своих без учёта регистра и не меняется после создания.
- **Права**: новые `catalog.read/manage`, `warehouses.read/manage` по матрице docs/06-stage2-plan.md §4. Справочники читают все роли; управляют владелец, админ, бухгалтер, менеджер продаж/закупок.
- **Аудит**: `currency.enabled/disabled`, `unit.created`, `unit.updated` (до/после); повторное включение без изменений не пишет событий.
- **Изоляция**: RLS на `organization_currency` и `unit_of_measure` (системные строки видны всем, но приложению недоступны для изменения; чужие единицы/валюты не видны и не меняются).
- **UI** на трёх языках: раздел «Справочники» в меню (виден при `catalog.read`), страницы «Валюты» и «Единицы измерения», подтверждение при отключении валюты, ошибки по кодам, карточки на мобильном.

## Что НЕ реализовано / ограничения
- **Курсов валют и пересчёта нет** — намеренно: источник курса, дату, округление и курсовые разницы определяет бухгалтер (Q6/Q9). В интерфейсе это прямо сказано. Суммы в разных валютах пока нигде не складываются.
- Набор валют фиксирован шестью; добавление валют — отдельная миграция (Q14 не подтверждён).
- Нет проверки «валюта используется» при отключении (использовать её пока нечему: появится с ценами товаров, срез 2.3). Аналогично для отключения единицы.
- Официальные коды единиц (классификатор) не заполняются: `official_code` пустой, источник не подтверждён (Q17).
- Общий каркас списков (поиск, фильтры, сортировка, пагинация) **не строился** в этом срезе: здесь списки короткие, а код без потребителя был бы мёртвым. Он создаётся в срезе 2.2 вместе с контрагентами.
- Права по складам добавлены, но экранов складов ещё нет (срез 2.4).
- Переводы названий валют/единиц на uz — мои, не проверены носителем. В dev-БД на сервере много тестовых организаций от E2E-прогонов.
- Внешний вид глазами не проверялся. Изменения закоммичены локально, в GitHub не отправлены.
