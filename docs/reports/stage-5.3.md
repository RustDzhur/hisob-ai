# Срез 5.3 — курсы валют, налоговые коды, отчёт в базовой валюте

План этапа: [docs/09-stage5-plan.md](../09-stage5-plan.md). По решению владельца выбор делается «как считается правильным, по источникам в интернете; поправим позже»; **все такие решения записаны в [docs/09-open-questions-recheck.md](../09-open-questions-recheck.md) (R10–R12) и требуют проверки бухгалтера.**

## Что сделано
- **Курсы валют** (к базовой валюте организации): с датой, номиналом, источником (`manual` / `cbu`).
  - **Вручную**: ввод/замена курса на день; валюта должна быть включена в организации; для базовой валюты курс не задаётся.
  - **С cbu.uz**: кнопка «Загрузить курсы ЦБ» (только при базовой валюте UZS). **Формат ответа проверен живым запросом** (`GET https://cbu.uz/ru/arkhiv-kursov-valyut/json/all/ГГГГ-ММ-ДД/` → список `{Ccy, Nominal, Rate, Date, …}`, курс — сумов за номинал). Если на запрошенный день курсы не опубликованы, сервис отвечает курсами другой даты — такой ответ **отклоняется**, чтобы не записать курс на неверную дату. Загружаются только включённые в организации валюты; ручные и ранее загруженные курсы не перезаписываются; ошибки сети/формата — понятные ответы 502 с подсказкой ввести курс вручную.
  - Поиск курса: последний известный на дату или ранее.
- **Налоговые коды (только НДС)**: код, название, ставка (0–100 %), период, источник и основание; **черновик → подтверждено** бухгалтером (основание обязательно), подтверждённый неизменяем, один «основной» код. Кнопка «Добавить справочный НДС 12 %» создаёт **черновик** со ставкой 12 % и источниками (spot.uz: в 2026 году НДС 12 %, для производителей сельхозпродукции при реализации 0 %; Deloitte: снижение с 15 % до 12 % с 01.01.2023) и пометкой, что бухгалтер должен сверить по lex.uz. Номер статьи Кодекса не проверялся и не указан.
- **Где используется налоговый код**: основной подтверждённый код НДС даёт в предложении проводки по документу **предупреждение** «налог не сходится со ставкой» (не блокирует). Налог система не рассчитывает и в проводки не подставляет.
- **Отчёт в базовой валюте**: оборотно-сальдовая ведомость с пересчётом иностранных проводок по курсу на дату проводки, округление half-up до знаков базовой валюты. Если для части проводок курса нет — отчёт помечается неполным с перечнем недостающих («валюта + дата»), проводки не теряются молча. Входящее сальдо учитывается.
- **Экспорт CSV** ведомости (в валюте проводок или в базовой): UTF-8 с BOM, `;`, заголовки `attachment`/`no-store`/`nosniff`, значения, похожие на формулы (`=`, `+`, `-`, `@`), обезврежены апострофом.
- Интерфейс: вкладки «Курсы» и «Налоги», переключатель «В базовой валюте» и «Скачать CSV» в ведомости, предупреждение в панели проводок по документу; uz/ru/en; аудит `exchange_rate.*`, `tax_code.*`.

## Что НЕ реализовано / ограничения
- **Нет переоценки и курсовых разниц** — пересчёт только справочный (R12). Нет автоматической ежедневной загрузки курсов (только по кнопке).
- Налоговые коды — только НДС; нет разных ставок по товарам/строкам, налоговых периодов и деклараций; **ставка 12 % и нулевая ставка — по открытым источникам, не проверены по тексту Кодекса** (R10).
- Допуск проверки налога (больший из двух минимальных единиц валюты и 0,5 % ожидаемого налога) — предварительный.
- Загрузка курсов ЦБ ходит во внешний сервис с сервера приложения; при его недоступности остаётся ручной ввод.
- CSV — только для ведомости; нет Excel/PDF.
- Переводы uz/en мои, носитель не проверял.
