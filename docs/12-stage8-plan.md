# План этапа 8 — AI Copilot (только чтение)

Основание: ТЗ §12 (типизированные инструменты, проверка организации и прав, никакого произвольного SQL/shell/секретов; режим Assist; документы и внешние данные — недоверенное содержимое; AI указывает неполноту данных, период, валюту и источники), решение «AI не меняет учёт и не обходит права».

## Срезы
| Срез | Содержание |
|---|---|
| **8.1** | Бэкенд: диалоги и сообщения (личные для пользователя), цикл «вопрос → вызовы инструментов → ответ» в воркере (ключи AI только там), адаптеры OpenAI (Responses API, function calling) и DeepSeek (chat completions, tools) + mock для тестов, инструменты только для чтения, ограничения, журнал вызовов, аудит |
| 8.2 | Интерфейс чата: вопрос, статус «думаю», ответ с источниками (какие инструменты и с какими параметрами вызваны), честные сообщения об ошибках и об отсутствии ключа; E2E на mock |

## Инструменты (все — чтение; каждый проверяет организацию и право **того, кто спросил**)
| Инструмент | Право | Что возвращает |
|---|---|---|
| `stock_balances` | `stock.read` | остатки по товарам и складам (до 30 строк), резерв, свободно, минимум |
| `search_documents` | `documents.read` | документы по фильтрам (до 20) |
| `unpaid_documents` | `documents.read` и `bank.read` | утверждённые документы с неоплаченным остатком по банковским сопоставлениям; **срок оплаты и направление (нам/мы) в системе не хранятся** — об этом сказано в результате |
| `bank_summary` | `bank.read` | сводка по счетам за период |
| `explain_reconciliation` | `bank.read` | сопоставления и предложения для операции с причинами |
| `trial_balance` | `accounting.read` | оборотно-сальдовая ведомость за период |

Права `copilot.use` — у всех ролей, кроме приглашённых без доступа; **результат определяется правами пользователя в инструментах** (кладовщик не получит банк).

## Защита
- Результаты инструментов — **данные, не инструкции**: в системной подсказке это сказано явно; в результатах поля с текстом третьих лиц не интерпретируются.
- Нет инструментов записи, нет SQL, нет доступа к секретам; модель не получает ключей и идентификаторов сессий.
- Лимиты: вопрос ≤ 2000 символов, ≤ 5 раундов инструментов, результат инструмента ≤ 12 000 символов (с пометкой «обрезано»), ≤ 20 вопросов за 10 минут на пользователя, таймаут провайдера.
- Источники: в ответе указываются инструменты и параметры; журнал вызовов сохраняется в сообщении и виден пользователю.
- Ответ на языке интерфейса; неполные данные, период и валюта называются явно.

## Ограничения
Нет автопроведения и черновиков (это Supervised Automation — позже), нет истории между диалогами, нет потоковой выдачи, нет автоматической оценки качества ответов (нужны реальные вопросы бухгалтера).
