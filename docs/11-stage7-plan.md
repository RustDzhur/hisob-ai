# План этапа 7 — интеграции

Основание: ТЗ §11 («Не выдумывать API endpoints, scopes, поля и наличие sandbox. До получения официальной документации и тестовых credentials интеграция имеет статус `MOCK` или `NOT_CONFIGURED`. UI явно показывает это»), `docs/05-roadmap.md` (этап 7 блокирован Q12).

## Что известно
Официальной документации и тестовых доступов Multibank, Faktura.uz, Didox **нет** (Q12 не закрыт). Поэтому реальных адаптеров нет и они не пишутся: ни адреса, ни поля, ни права доступа не придумываются.

## Срез 7.1 (единственный срез этапа до получения документации)
| Что | Как |
|---|---|
| Контракт адаптера | Единый интерфейс: описание провайдера (код, название, вид, статус, получена ли документация, возможности) и операция синхронизации с курсором. Контракт описывает, что обязан реализовать будущий адаптер (auth, capabilities, pagination, rate limits, retries, webhooks, cursor, error mapping — по ТЗ) |
| Реестр провайдеров | `multibank`, `faktura_uz`, `didox` — `NOT_CONFIGURED` (адаптера нет, возможности пусты, подключить нельзя); `generic_file` — `AVAILABLE` (это уже готовые загрузка выписок CSV/XLSX и загрузка документов; ведёт в эти разделы); `mock` — `MOCK` (тестовый адаптер для проверки механики: курсор, повтор, журнал; **ничего не пишет в учёт**) |
| Журнал синхронизаций | Таблица запусков: провайдер, режим (MOCK), курсор до/после, число записей, статус, ошибка, кто запустил; повтор безопасен: тот же `request_id` возвращает тот же запуск, курсор не сдвигается дважды; параллельные запуски сериализуются |
| Интерфейс | Раздел «Интеграции»: карточки провайдеров с честным статусом («документация не получена», «тестовый режим — данные не настоящие»), без кнопок «Подключить» там, где подключать нечего; журнал запусков |
| Права | `integrations.read` (owner, org_admin, accountant, auditor), `integrations.manage` (owner, org_admin) — предложение R15 |
| Секреты | Хранилища секретов пока нет: ни один провайдер не принимает ключей. Когда появится реальный адаптер — шифрование на стороне сервера, секрет не возвращается клиенту (требование ТЗ §7); в 7.1 это не реализуется, чтобы не создавать неиспользуемый код |

## Чего НЕ делаем
Адаптеры Multibank/Faktura.uz/Didox, webhooks, OAuth, хранение ключей, автоматическая загрузка выписок/ЭСФ, scraping.

## Что нужно от владельца (Q12)
Официальная документация API, тестовые доступы, список разрешений и примеры ответов по каждому провайдеру.
